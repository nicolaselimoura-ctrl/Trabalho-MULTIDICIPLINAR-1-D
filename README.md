# Trabalho-MULTIDICIPLINAR-1-D
Dados de Treinamento
Conjuntos de dados (textos, imagens, tabelas) usados para ensinar o modelo a reconhecer padrões e prever resultados. Dados limpos, variados e representativos garantem maior precisão e capacidade de generalização da IA.
Viés na IA
Ocorre quando o modelo aprende com dados desequilibrados ou com preconceitos históricos da sociedade. Como a máquina não tem opinião própria, ela acaba por reproduzir e ampliar injustiças se a amostragem não for auditada pelo cientista de dados.
Overfitting (Superajuste)Erro estatístico em que o modelo decora os dados de treino em vez de aprender a lógica do problema. Ele tem excelente desempenho nos dados antigos, mas falha ao analisar dados inéditos no mundo real. 
Algoritmos de RecomendaçãoModelos que analisam variáveis de entrada $X$ (tempo de tela, cliques, horários) para prever a variável resposta $y$ (engajamento). Sem variação de conteúdo, geram o isolamento do utilizador em bolhas digitais.   
Privacidade e Guardrails
A conformidade com leis de privacidade (LGPD) exige a remoção de colunas com dados sensíveis (df.drop). Para além disso, utilizam-se Guardrails (travas no Prompt do Sistema) para evitar alucinações, vazamentos e respostas inadequadas.
Futuro da IAO avanço da tecnologia exige um compromisso ético dos profissionais, garantindo que o desenvolvimento de novos modelos seja transparente, seguro, auditável e benéfico para a sociedade.   
Conclusão
A Inteligência Artificial depende da união da Ciência de Dados (que limpa dados, normaliza métricas e treina modelos preditivos) com as Técnicas Integradas (que aplicam Guardrails, governança de privacidade e regras éticas). Essa integração garante que o produto final seja estatisticamente preciso e seguro para o uso no dia a dia.
